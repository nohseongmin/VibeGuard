# VibeGuard 시연영상 대본 (자동 데모용)

이 대본은 `demo/demo.html` 자동 재생 화면의 해설이다. demo.html은 한국어 음성 해설을 브라우저 TTS로 자동 재생하므로, 직접 읽지 않아도 목소리가 들어간다(녹화할 때 시스템 소리가 함께 녹음되게만 하면 된다). 아래 문장은 그 해설 내용이며, 직접 읽거나 자막용으로 참고해도 된다. 1.25배속으로 진행되어 전체 약 1분 50초 내외다.

## 녹화 방법 (Windows 11)

시작 화면에 체크리스트가 그대로 떠 있으니, 화면을 따라가기만 하면 된다.

1. `demo/demo.html` 을 더블클릭해 브라우저(크롬/엣지)로 연다. **F11** 로 전체화면.
2. 시작 화면의 **🔊 음성 테스트** 버튼을 눌러 소리가 들리는지 먼저 확인한다.
   - 버튼 옆에 `✅ 한국어 음성 준비됨` 이 떠야 정상이다(이 PC는 Microsoft Heami 확인됨).
   - `⚠️ 한국어 음성 없음` 이면 `설정 › 시간 및 언어 › 음성` 에서 한국어 음성을 추가한다.
3. **Win + Alt + R** 로 화면 녹화를 시작한다. (윈도우 기본 기능, 설치 불필요)
4. 화면을 **클릭**(또는 스페이스) → **3-2-1 카운트다운** 후 자동 재생된다.
   카운트다운 동안 마우스를 화면 밖으로 치우면 커서가 영상에 안 잡힌다(재생 중에는 커서가 자동으로 숨겨진다).
5. 마지막 **VibeGuard 브랜드 화면에서 멈추면 끝**이다(검은 화면으로 끝나지 않는다).
   상단 진행바가 100%가 되고, 5초 뒤 우측 하단에 "녹화를 멈추세요" 안내가 뜬다.
6. **Win + Alt + R** 로 정지한다. 영상은 `내 PC \ 동영상 \ 캡처` 에 저장된다.
7. 유튜브에 업로드(공개 또는 일부공개)하고 URL 을 결과보고서 '시연영상' 칸에 기재한다.

### 알아 두면 좋은 것
- **다시 찍고 싶으면 `R` 키** — 처음 시작 화면으로 즉시 되돌아간다.
- **소리가 녹음되지 않는다면**: Xbox Game Bar(`Win+G`) › 설정 › 캡처 중 › "녹화할 오디오"를 **모두**로 바꾼다.
- 해설 음성은 브라우저가 읽어 주므로 직접 말할 필요가 없다. 조용한 곳에서 마이크를 끄고 녹화하면 깔끔하다.
- 화면은 어떤 해상도에서도 꽉 차게 자동 확대된다(1080p 기준 약 1862×1048).

## 해설 (장면 순서대로, 괄호는 화면 표시 시간)

장면 1 — 인트로 (약 9초)
"요즘은 코딩을 몰라도 AI에게 맡겨 앱과 서비스를 만드는 시대입니다. 이걸 바이브코딩이라고 합니다. VibeGuard는 그렇게 만든 코드의 보안을 지켜 주는 도구입니다."

장면 2 — 왜 필요한가 (약 10초)
"문제는, AI가 만든 코드의 약 45퍼센트에 보안 취약점이 섞여 있다는 분석이 있다는 점입니다. 하드코딩된 키, 위험한 코드 실행, 가짜 패키지까지. 비전문가에게 보안은 너무 어렵습니다."

장면 3 — 앱 실행 (약 10초)
"사용법은 이게 전부입니다. 내려받은 실행파일을 더블클릭하면 이 창이 뜹니다. 검사 실행, 이전 검사 결과, 설정. 버튼 세 개뿐입니다."

장면 3-B — 폴더 드래그앤드롭 (약 10초)
"검사 실행을 누르고, 검사할 폴더를 창에 끌어다 놓기만 하면 됩니다. 터미널도, 브라우저도, 파이썬도 필요 없습니다."

장면 3-C — 결과가 창 안에 (약 11초)
"놓는 즉시 검사가 돌고, 결과가 같은 창 안에 바로 나옵니다. 점수와 등급, 그리고 무엇이 왜 위험한지까지 한 화면에서 볼 수 있습니다."

장면 4 — 탐지 결과 (약 13초)
"그러면 숨어 있던 문제들이 심각한 순서대로 정리되어 나옵니다. eval로 외부 입력을 실행하는 치명적 문제, TLS 인증서 검증을 꺼 버린 설정, 약한 MD5 암호까지. 각 항목마다 어디가, 왜 위험하고, 어떻게 고치는지 알려 줍니다."

장면 5 — 슬롭스쿼팅 (약 11초)
"가장 특징적인 기능입니다. AI가 지어낸 가짜 패키지, 슬롭스쿼팅까지 잡아냅니다. reqeusts나 expres처럼 유명 패키지와 한두 글자 다른 이름인데, 공격자가 이 이름을 미리 선점해 악성코드를 심습니다. 일반 보안 도구는 놓치는 위협입니다."

장면 5-B — 알려진 취약점(CVE) (약 11초)
"여기에 더해, 쓰고 있는 라이브러리의 알려진 취약점(CVE)도 실시간으로 확인합니다. 어제 공개된 취약점도 도구를 업데이트하지 않고 바로 반영됩니다. 취약점 목록을 내장하지 않고 OSV.dev에 물어보기 때문입니다."

장면 6 — 점수 (약 9초)
"모든 결과는 0부터 100까지 보안 점수로 요약됩니다. 이 예제 앱은 0점, F등급이네요. 위험도를 한눈에 알 수 있습니다."

장면 7 — 이전 검사 결과 (약 10초)
"지난 검사들은 최신순으로 쌓여서, 언제든 다시 열어 볼 수 있습니다. 고치기 전과 후를 비교하기 좋습니다."

장면 8 — 마무리 (약 10초)
"코드 규칙 54개에 슬롭스쿼팅과 CVE 실시간 검사까지, 6개 언어 지원, 외부 의존성은 0. AI가 만든 코드를 더 안전하게. VibeGuard였습니다. 감사합니다."

## 직접 시연하고 싶다면 (대안)
자동 데모 대신 실제 앱 화면을 녹화해도 된다. `dist/VibeGuard.exe` 를 더블클릭(또는 `python -m vibeguard app`)해 창을 띄우고, `examples` 폴더를 창에 끌어다 놓아 검사되는 과정을 그대로 캡처한다. 데모에 쓰인 화면들은 모두 이 앱을 실제로 캡처한 것이다. 위 해설을 그대로 쓰면 된다. 슬롭스쿼팅(장면 5)을 가장 강조하고, 마지막에 저장소 주소(github.com/nohseongmin/VibeGuard)를 보여 준다.
